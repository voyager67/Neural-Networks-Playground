# Neural Playground — Complete Edition

## Included

- Interactive browser MLP for 2D binary classification.
- Five deterministic synthetic datasets with adjustable sample count, noise, and seed.
- Configurable hidden architecture, four activation choices, and three optimisers.
- Training controls, live metrics, decision-boundary and loss plots.
- SVG network explorer with weight, gradient, and activation modes plus a neuron inspector.
- Four-configuration experiment lab with chart, table, and CSV export.
- Model JSON import/export and dataset CSV export.
- Concept lessons, model guide, responsive layout, theme toggle, local session persistence, and service-worker shell cache.
- NumPy reference MLP, command-line experiment runner, unit tests, and Matplotlib plots.
- GitHub Actions workflows for quality checks and GitHub Pages deployment.

## Limitations

This release is an educational binary-classification lab. It reports training metrics, uses synthetic samples, and does not claim real-world generalisation or serve as a production ML framework. Browser and Python results are not expected to match bit-for-bit.
