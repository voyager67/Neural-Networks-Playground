# Contribution workflow

1. Search existing issues and discussions before opening a new one.
2. For a feature, first describe the learner problem and how you will tell it is solved.
3. Make the smallest complete change and update docs/tests together.
4. Run both JavaScript and Python test commands from `README.md`.
5. For numerical changes, add a finite-difference gradient check or another independent mathematical test.
6. For UI changes, include keyboard behaviour and a narrow-screen check in the pull request description.
7. Explain known trade-offs, browser support, and compatibility impact.

Good first issues: clearer activation intuition, more explanatory tooltips, better contrast, test coverage for imported model JSON, extra synthetic data with a deterministic generator, or a comparison export enhancement.
