# Code of Conduct

We want Neural Playground to be a welcoming, curious, and constructive learning space.

## Expected behaviour

- Be respectful and assume good intent.
- Explain disagreement with evidence and kindness.
- Welcome beginner questions and make technical explanations accessible.
- Critique ideas and implementations, not people.
- Respect privacy and do not post private data, credentials, or personal attacks.

## Unacceptable behaviour

Harassment, discrimination, threats, doxxing, intimidation, and deliberately disruptive conduct are not acceptable.

## Maintainer response

Project maintainers may edit or remove harmful content, close discussions, or restrict participation when needed to keep the community safe. Report concerns privately through GitHub's available reporting mechanisms.

This code applies to project discussions, issues, pull requests, and other spaces where the community represents the project.
