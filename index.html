What is a decision boundary?

01 / 04

A decision boundary is the line or surface a classifier uses to separate classes. A neural network creates it by composing simple mathematical transformations. Watch this map evolve as the loss decreases.

ŷ = σ(W₂ · φ(W₁x + b₁) + b₂)

THE CORE IDEA

Learn a function from examples.

A neural network is a chain of parameterised transformations. Training adjusts those parameters so predictions become more useful on examples with known labels.

01
◉

Neurons & layers

Each neuron combines inputs with weights, adds a bias, and applies an activation function. Layers compose these small operations into a flexible model.

z = w · x + b
Try thisAdd a hidden layer or change the neuron count in Playground.
02
⌁

Activation functions

Non-linear activations allow networks to represent curved and complex boundaries. Without non-linearity, stacked dense layers collapse into one linear transformation.

a = φ(z)
Try thisCompare Tanh, ReLU, Leaky ReLU and Sigmoid.
03
↘

Loss & gradients

Loss measures the cost of predictions. Backpropagation applies the chain rule to estimate how each parameter contributes to that cost.

∂L / ∂w
Try thisSwitch the network map to Gradients after training.
04
⇢

Optimisation

An optimiser turns gradients into parameter updates. SGD, Momentum and Adam use different rules, each with trade-offs in speed and stability.

w ← w − ηg
Try thisRun the same dataset with different optimisers.
05
◌

Generalisation

A model can memorise examples without learning a reliable pattern. Noise, dataset shape and model capacity all influence how a boundary behaves.

Train ≠ unseen data

Experimental thinking

Change one variable, record the outcome, and repeat from comparable initial conditions. A single run is an illustration, not proof of a general claim.

Hypothesis → test → evidence

Glossary

Small words, big ideas.

Epoch

One complete pass over all training examples.

Batch

A subset of examples used to calculate one update.

Learning rate

The step scale used when updating model parameters.

Bias

A trainable offset that shifts a neuron's response.

Parameter

A learnable value, such as a weight or bias.

Decision boundary

The region where the predicted class changes.

MODEL CONTRACT

What this lab trains

A fully connected multilayer perceptron for two-dimensional, binary classification. The input layer has two features and the output is a single sigmoid probability.

input (2) → hidden layers → sigmoid (1)

Hidden widths are configurable (1–4 layers, 2–32 neurons per layer). The demo uses synthetic data and runs training locally in the browser.

OBJECTIVE

Binary cross-entropy

The output probability is compared with a binary target. Numerical clamping keeps the logarithm finite near 0 and 1.

L = −[y log(p) + (1−y) log(1−p)]

With sigmoid output and binary cross-entropy, the output-logit derivative simplifies to p − y.

OPTIMISERS

Three update rules

SGD applies the current gradient. Momentum smooths updates with a running velocity. Adam adapts each parameter's update using first and second gradient moments.

SGD: w ← w − ηg

All optimisers use the same binary objective and training examples for a fairer, though still illustrative, comparison.

REPRODUCIBILITY

Export and repeat

Export the current model weights as JSON, or the exact synthetic points as CSV. The browser model file includes its architecture, activation, optimizer, learning rate and parameter arrays.

PYTHON TRACK

NumPy + Matplotlib

The repository also contains a small NumPy implementation and a command-line experiment script. Use it for saved metrics, reproducible seeds and decision-boundary plots.

python -m pip install -r requirements.txt
python scripts/train_numpy.py --dataset xor

Browser experiments and Python runs are separate execution paths; their results are not expected to match exactly because their random-number streams differ.

LIMITS & SAFETY

Learning demo, not a benchmark

Small synthetic datasets are intentionally simple. Training accuracy is measured on the generated training examples and should not be interpreted as generalisation performance.

For research claims, use separate validation/test data, multiple seeds, explicit baselines, and report uncertainty.

All browser training happens on your device.Review security and research guide.
